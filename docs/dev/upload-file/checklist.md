# Checklist

## Node.js BFF 上传网关
- [ ] BFF 服务可正常启动，监听端口 3001
- [ ] JWT 鉴权中间件正常工作，无 token 请求返回 401
- [ ] `POST /api/upload/chunk` 能正常接收并存储分片
- [ ] `GET /api/upload/check?fileHash=xxx` 能正确返回已上传分片列表
- [ ] `POST /api/upload/merge` 能正常合并分片并清理临时文件
- [ ] `POST /api/upload/direct` 能正常接收小文件
- [ ] 合并完成后 BFF 成功回调 Java 后端接口
- [ ] Magic Number 校验能识别并拦截伪装类型的文件
- [ ] 分片缺失时合并接口返回 400 并提示缺失索引

## 前端分片上传
- [ ] `chunked-upload.js` 能正确计算文件 SHA-256 哈希
- [ ] 文件 > 10MB 时走分片上传流程
- [ ] 文件 ≤ 10MB 时走直传流程
- [ ] 上传过程中实时展示进度百分比和已上传/总大小
- [ ] 上传中断后重新选择相同 hash 文件能续传

## 提交页面
- [ ] `/normal/submission` 路由可正常访问
- [ ] 表单包含项目名称、项目描述、项目文件、PPT 文件四个字段
- [ ] 必填字段为空时提交按钮禁用并提示
- [ ] 文件类型/大小不合法时表单校验拦截并提示
- [ ] 提交成功后显示成功反馈并刷新记录列表

## 提交记录列表
- [ ] 页面底部展示历史提交记录
- [ ] 每条记录显示提交时间、项目名称、审核状态
- [ ] 支持分页浏览

## 入口
- [ ] 首页快捷入口中 `normal` 角色能看到"提交作业"按钮
- [ ] Vite 开发代理正确转发 `/api/upload` 到 BFF
- [ ] 动态路由菜单配置说明提交给后端
